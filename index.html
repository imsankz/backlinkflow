How it works

Five commands from install to proof

Plan dry, then go live. Every run is paced, logged, and screenshotted.

1

Install & initialize

Install the CLI globally, then run backlinkflow init to write a starter config file with sensible defaults.

2

Point it at your AI endpoint

Add your site details and any OpenAI-compatible endpoint — OpenAI, Anthropic, Groq, OpenRouter, or a local Ollama / LM Studio / vLLM server — to linkflow.config.json and .env.local.

3

Plan it with --dry-run

Preview exactly which directories would be submitted and what copy would be used, without recording or sending anything.

4

Submit for real with --go

Playwright launches headless Chromium, detects each directory's form fields, and fills + submits automatically, pacing itself per day.

5

Check status & pull the report

backlinkflow status shows submitted / pending / failed; backlinkflow report regenerates the markdown with screenshots.

Commands

Plan dry, then go live

Copy, paste, ship. Works with npm, pnpm, yarn and bun.

# plan vs execute

# extras

backlinkflow indexnow https://yoursite.com
backlinkflow measure https://yoursite.com

backlinkflow report   # → .linkflow/report.md

Tip: start with --limit 10 and inspect .linkflow/report.md before scaling to --limit 100.

FAQ

Everything people ask before their first run

If it's not here, open an issue on GitHub — we answer fast.

Is BacklinkFlow really free?

Yes. It's MIT-licensed and costs $0 to run — you only need access to an AI endpoint, and free local models through Ollama, LM Studio, or vLLM work fine.

Do I need an OpenAI account?

No. BacklinkFlow works with any OpenAI-compatible endpoint, including OpenAI, Anthropic, Groq, OpenRouter, or a local model server.

What's the difference between --dry-run and --go?

--dry-run generates and shows the submission plan without recording or sending anything. --go launches a real headless Chromium browser through Playwright and actually fills in and submits the forms.

How many of the 1,123 directories are actually usable?

876 are live-verified through concurrent HTTP and DNS checks, 221 are flagged dead with a reason, and 26 are marked paid-only — tracked transparently instead of padding the count.

Can I run it for more than one product?

Yes. BacklinkFlow is config-driven, so each site gets its own configuration file and you can run submissions for multiple products from one install.

How is this different from Submitator, ListingBott, or BoringLaunch?

Those charge $29 to $499 for a directory list, AI-written copy, and a status report. BacklinkFlow provides the same three things for $0, plus it's self-hostable and fully open source.
