What BacklinkFlow Does

Three things every paid directory submission service bundles into one dashboard. We do the same three, but free, self-hostable, and with your own AI endpoint.

📋

1,123 Vetted Directories

Across 9 categories (SaaS, AI, travel, startup, general, community, reddit, etc.). Merged from 11 open-source lists, deduplicated, and live-verified. 876 confirmed alive, 221 marked dead with reason, 26 marked paid.

🤖

AI-Tailored Copy

Per-directory tagline + description matching your site's voice. Uses your AI endpoint — typically free via OmniRoute or OpenAI-compatible APIs.

🦭

Playwright Automation

Real browser submissions via --go. Headless Chromium with smart field detection. Handles complex forms, CAPTCHAs via manual checkpoint, and per-site pacing.

📸

Proof of Submission

Screenshots + per-directory markdown report. .linkflow/report.md + .linkflow/proofs/*.png — the same proof format Submitator charges for.

🔍

Live Verification

876 directories live-checked via scripts/check-urls.py (concurrent HTTP + DNS). 221 marked dead with reason. 26 marked paid. No padding with self-owned link farms.

⚙️

Multi-Site Support

One tool, multiple products. Each site = its own config file. Works with SaaS, travel blogs, dev tools, or any site.

Quick Start

Get your first submissions planned in under a minute.

# 1. Install
npm install -g backlinkflow

# 2. Initialize + edit config (.env.local with your AI endpoint)
backlinkflow init

# 3. Explore the database
backlinkflow stats
backlinkflow list --category startup --limit 10

# 4. Generate AI-tailored copy (dry-run, no submission)
backlinkflow submit https://yoursite.com --dry-run --limit 10

# 5. Real automation — Playwright submits for you
backlinkflow submit https://yoursite.com --go --limit 10

# 6. Track progress
backlinkflow status
backlinkflow report
